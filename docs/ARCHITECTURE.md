All of `core/`, `captions/` and `media/` build into `shyftr_engine` (Qt Core/Gui/Concurrent, no widgets), which the tests exercise directly.

## Data model
- **Time** is `int64` microseconds on one project time base. Frame maths uses exact rationals (`30000/1001`), so mixed-rate sources never drift.
- **Clips** reference media by id with a source range (`in`, `out`), timeline `start` and `speed`. Linked audio/video share a `linkId`.
- **Transcripts** store words in *source* time (for media-bound transcripts) or timeline time (imported SRT). Each word carries confidence, an `edited` flag and a `hardBreakBefore` flag. **Cues** are word-index ranges with optional speaker, per-cue style overrides and a `manual` flag.
- **Caption tracks** bind a transcript to a template id plus style overrides and a burn-in flag.
- **CaptionMapper** maps transcripts through every clip of the bound media (audio clips preferred, linked pairs deduplicated). Captions therefore follow trims, splits, moves, speed changes and deletions without any extra bookkeeping.

## Persistence (no database)
- `project.json` uses versioned schema 2 with explicit tested migrations (`v1 → v2`). Newer schemas are refused and the file is left untouched.
- **Save:** validate → serialise → parse the bytes back → copy the old file to `backups/` (rotating) → `QSaveFile` atomic rename. Invalid projects are never written.
- **Autosave:** rolling `autosaves/autosave-*.json` written outside the save transaction.
- **Crash detection:** `autosaves/session.json` (clean-shutdown flag) plus a `QLockFile`. On reopen, if the session ended uncleanly and an autosave is newer, the user is offered recovery.
- If `project.json` is unreadable, the newest valid backup is loaded and the user is told.
- Media paths are stored both absolute and project-relative. Missing media is matched by name and size in the relink workflow. Collect/package produce portable projects.

## Render pipeline (export)
`ExportGraph` builds a deterministic FFmpeg filter graph, written to a script file to avoid command-line limits:
1. **Per clip:** input-seek `-ss/-t` → `setpts` (speed) → `fps` (CFR conform; handles VFR) → crop → flip → rotate → colour (`lutrgb` + `colorchannelmixer`, generated by `ColorMath`) → scale → opacity → alpha fades → exact frame count → placed on a transparent canvas.
2. **Per video track:** clips and transparent gaps are concatenated into one exact-length RGBA stream.
3. **Composite:** tracks are overlaid bottom→top on the background colour.
4. **Graphics:** titles, shapes and burned-in captions are drawn by `OverlayScene` (the same code as the viewer) and streamed as raw RGBA frames into FFmpeg's stdin, then overlaid.
5. **Audio:** each clip gets trim → `atempo` chain → resample → gain → fades → exact length → `adelay` → `amix` → padded and trimmed to the timeline length.
6. **Encode:** hardware encoder when available (VideoToolbox / NVENC / QSV / AMF), otherwise libx264/libx265. Output goes to `*.partial.*` and is renamed only on success.

## Preview
`PreviewEngine` keeps a small LRU pool of `QMediaPlayer` decoders (one per visible video clip, plus pre-roll of the next clip) and separate audio decoders. These are synchronised to a master clock with drift correction. Frames are composited with the export geometry (`computeGeometry`) and colour (`ColorMath`), then `OverlayScene` draws titles and captions. Preview resolution is selectable (Full / Half / Quarter) for slower machines.

## Speech pipeline
`TranscriptionJob`: FFmpeg extracts 16 kHz mono PCM → envelope and speech regions → `whisper-cli -ojf` (token offsets and probabilities; optional `--vad`, prompt, GPU off, thread count) → `WhisperParser` builds words from tokens (merging punctuation and sub-words, dropping non-speech markers) → `Aligner::refine` → `Segmenter` (pause, sentence-end including the Devanagari danda, word/char limits, max/min duration, keeping manual cues). The model's SHA-256 is verified before use.

## Design decisions vs. the plan
| Plan suggestion | Choice here | Why |
|---|---|---|
| Qt 6 + QML UI | **Qt Widgets** with QDockWidget | The plan's Advanced Editor needs dockable panels; Widgets provides native docking, keyboard focus and accessibility without a custom docking layer. A QML front end can be added on the same engine. |
| MLT framework | **Own timeline model + FFmpeg filter-graph renderer** | Keeps the core small and testable, avoids an additional GPL/LGPL module surface, and guarantees preview/export parity through the shared renderer. `ExportGraph` is the seam if MLT is adopted later. |
| whisper.cpp / FFmpeg as libraries | **Separate local executables** | This gives crash isolation for AI jobs (matching the plan's "AI worker … isolated jobs"), easy model/engine upgrades and clean licence separation. Nothing leaves the machine. |
| libass for captions | **Custom QPainter renderer** (+ ASS export) | One renderer for preview and export enables the kinetic effects (pop, karaoke fill, reveal) and pixel-tested parity. ASS is still produced for interchange. |

## Roadmap hooks
- **Keyframes:** add per-property keyframe lists to `Transform`/`ColorAdjust`. The export side maps them to FFmpeg expressions and the preview evaluates them per frame.
- **Proxies:** `MediaCache` already owns per-project cache folders. Add a proxy job and make `PreviewEngine::slotFor` prefer proxy paths.
- **Diarization / denoise / translation:** add new `TranscriptionJob` stages. Cues already carry speaker ids.
- **Interchange:** OpenTimelineIO export from `Project` (tracks and clips map directly).
