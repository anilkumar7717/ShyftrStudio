Shyftr Studio for Windows
=========================

Run "Shyftr Studio.exe". Everything works offline; nothing is uploaded.

FFmpeg (ffmpeg.exe, ffprobe.exe) and whisper.cpp (whisper-cli.exe) are included in this folder.

Before generating captions, add a speech model once:
  1. Download a model, e.g. ggml-small.bin from
     https://huggingface.co/ggerganov/whisper.cpp/tree/main
  2. In Shyftr Studio: Preferences -> AI Models -> Add model file...

Your projects are saved in Documents\ShyftrStudio\Projects.
